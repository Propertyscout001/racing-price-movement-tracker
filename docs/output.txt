racing-price-movement-tracker - captured terminal output
========================================================

Every block below is real, unedited output from pricemove.py in this repository.
Nothing is hand-written, reordered or invented. The only thing removed is the API
key itself, which the tool reads from the PE_API_KEY environment variable and
never prints.

Machine:  macOS (darwin 24.6.0), Python 3.9.6, no third-party packages installed.
Clock:    local time is AEST (UTC+10), so the UTC date is one day behind the
          local date for these late-evening-UTC runs.

Two capture sessions, both before the Australian card opened for the day:

  session 1  2026-09-14 23:31-23:44 UTC  (2026-09-15 09:31-09:44 AEST)
  session 2  2026-09-15 00:08-00:25 UTC  (2026-09-15 10:08-10:25 AEST)

The first Australian race of that day jumped 11:38 AEST, and /v1/racing/movers
only covers races already inside the ~60-minute price-capture window, so an
empty Australian scan at those hours is the correct answer rather than a
filter mistake. That timing is visible throughout the blocks below.
